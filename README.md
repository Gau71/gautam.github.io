# Gautam Sahu - Portfolio

Modern, responsive personal portfolio website.

**Live:** https://gau71.github.io/gautam.github.io/

## Features
- Dark theme with cyan / purple / neon green accents
- Smooth typing animation in hero
- Fully responsive (mobile + desktop)
- Skills progress bars
- Project cards with live demo + GitHub links
- Certificates gallery
- Contact form + Google Maps
- Scroll-to-top button & active navigation

## How to run locally
Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Tech
- HTML5
- CSS3 (Custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript
